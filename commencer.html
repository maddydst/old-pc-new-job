Commencer de zéro

Rien à installerpour commencer.

Pas besoin de savoir coder, ni d'installer un logiciel de développeur. Tu commences dans Claude, depuis ton navigateur. Copie les messages ci-dessous, colle-les, laisse-toi guider. Pour refaire tout mon parcours, va directement à l'étape 4.

Étape 1
  1. 1

    5 minutes

    Ouvrir Claude dans le navigateur

    Va sur claude.ai et crée un compte. Rien à télécharger. Note le modèle de ton vieil ordinateur, son année et sa mémoire (sur Mac : menu Pomme, « À propos de ce Mac » ; sur Windows : Paramètres, Système, Informations système).

  2. 2

    Pour commencer

    Coller le message de départ

    Ouvre une nouvelle conversation et colle ce message, en remplaçant ce qui est entre crochets. Claude te pose quelques questions, puis te propose un plan d'un projet par étape, adapté à toi.

    Message de départ
    Bonjour Claude. J'ai un ancien ordinateur : [modèle, année, mémoire]. Je ne sais pas coder et je n'ai rien installé.

Je veux le transformer petit à petit en « maison » pour des agents IA qui m'aident au quotidien : ranger mes idées, me tenir à jour sur un sujet, tenir un journal de ce que je fais. Un petit projet par étape.

Mes règles :
- explique simplement, une étape à la fois, et dis-moi exactement quoi cliquer ou taper ;
- ne me fais jamais coller une clé secrète ou un mot de passe dans la conversation.

Commence par me poser 3 questions sur mes envies, puis propose un plan de 6 étapes et détaille l'étape 1.
  3. 3

    Pour commencer

    Voir une première version, toujours sans rien installer

    Claude peut afficher une petite page directement dans la conversation. Demande-lui par exemple ton tableau de bord de départ :

    Premier essai
    Fais-moi une page web d'une seule page, affichée ici dans la conversation : le tableau de bord de mon labo. Un tableau avec les 6 étapes du plan (étape, projet, statut, temps, ce que j'ai appris), en mode sombre, simple et lisible.
  4. 4

    Quand tu te sens prêt·e

    Passer à Claude Code, sans logiciel de développeur

    Pour que tes agents tournent vraiment sur le vieil ordinateur, il faut que Claude puisse y écrire des fichiers. Installe l'application Claude pour ordinateur (claude.ai/download) : son onglet « Code », c'est Claude Code, sans terminal ni éditeur à installer à part.

    Dans l'onglet Code, choisis un dossier vide. Le plus simple pour refaire mon parcours : colle tous les prompts d'un coup, Claude Code avance avec toi une étape à la fois.

    Ou, pour suivre ton propre plan (celui de l'étape 2), colle plutôt :

    Premier message dans Claude Code
    Crée-moi un labo dans ce dossier :
- un fichier JOURNAL.md avec un tableau : étape, projet, statut, temps, ce que j'ai appris ;
- un fichier CLAUDE.md qui dit qui je suis (je débute, je ne code pas) et les règles du labo : aucune clé secrète dans le code (tout dans un fichier .env), un projet par étape, lire JOURNAL.md au début de chaque projet et le mettre à jour à la fin.

Ensuite, aide-moi à faire l'étape 1 de ce plan : [colle ici le plan que Claude t'a proposé].
  5. 5

    Un peu plus tard

    Parler à tes agents depuis le téléphone

    Telegram permet de créer un bot en quelques minutes. Demande à Claude Code de te guider : il te dira quoi faire dans Telegram, et la clé du bot ira dans le fichier .env, jamais dans la conversation.

    Brancher Telegram
    Je veux parler à mon labo depuis mon téléphone avec un bot Telegram qui tourne sur cet ordinateur, et qui redémarre tout seul s'il plante. Guide-moi étape par étape (création du bot, où ranger la clé dans .env, lancement automatique).
  6. 6

    Ensuite

    Un agent par étape

    Un agent pour ranger tes idées, un pour la veille du samedi, un pour tenir ton journal… ou ceux dont tu as besoin, toi. Chaque étape, une brique, notée dans le journal. Le parcours complet donne un prompt à copier pour chacune des 11 étapes.

    Le plus simple : copie tout le parcours en un seul message et colle-le dans Claude Code. Il commence par l'étape 1 et attend ton « étape suivante » pour continuer.

    Un prompt par étape

Deux réflexes qui m'ont évité des ennuis : ne jamais coller de clé secrète dans une conversation, et préférer une règle simple à l'IA quand elle suffit.

À toi de jouer.

Et si tu veux voir où ça peut mener, tout est dans le parcours.
